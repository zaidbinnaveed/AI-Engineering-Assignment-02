Behind the benchmark Methodology & limitations +
This is a history-assisted planning task: GPT-OSS and the inverse control receive the scramble. The model generates its own moves through a real HTTP request; the cube engine applies them and checks all 54 facelets. BFS searches from the state with a depth and node budget. A missing reference means the search budget was reached, not that no solution exists.
The cube is a 2D unfolded net. Replay shows actual state transitions, one move at a time. Free anonymous inference may be slow, cached, rate limited, or unavailable. Errors appear explicitly and never become simulated model successes. Latency measures the full HTTP request, not internal model compute. This single puzzle is not a general model leaderboard.
